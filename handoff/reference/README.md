# reference/

How things actually behave — the durable facts a requirement leans on. Add a file
here when you verify something worth not re-deriving: the `localStorage` schema and its
migration path, how the recommendation increments resolve, any browser/Pages quirk.
Empty at setup; fills as things get pinned down.

- `PAGES.md` — each page's live decisions, marked Emilio's (E) or Planner's (P); feedback is checked against it (DEC-137).
- `schema.md` — the stored data's shape.
- `inspiration-repos.md` — other apps' licences and the ideas taken.
