## Technical

### What changed
1. **Swap without history: no step (DEC-106).** `mid-workout-pick.js`: new `swapNoHistoryItem(original)` (copies `sets` and
   `restSec`, with `targets`/`suggestedWeights`/`durations` empty, role main, no warm-up, no notes) and `swapPicks(picks, original)`
   (a history pick keeps its item, a no-history pick gets the copy). `MidWorkoutPicker` takes a new `copyFrom` prop. When it is set,
   `onPick` commits straight away with `swapPicks`, so the step never shows. `replace.jsx` passes `copyFrom={item}`. Add exercise
   passes nothing, so it still has DEC-104's step. The picker's no-history row reads "No history — same sets and rest" on Swap.
2. **Select on focus.** `Field` has a new `selectOnFocus` prop. It selects on focus and swallows the one mouseup that follows,
   so a click doesn't collapse the selection to a caret. It is used on SetLogForm kg, Reps and Duration (s), and on SetEditForm
   kg, Reps and Duration (s). No other screen changed.
3. **Empty Reps.** `required` is removed from the reps `Field`. On Complete, a blank (or whitespace-only) Reps on a non-timed set
   shows "Enter reps" (`ui-field-error`, role alert, under the number row) and does not call `onComplete`. The next reps edit clears
   it. A cardio form whose label is "Duration" reads "Enter duration". Nothing is prefilled.
4. **Routine-kg sheet.** `offerSheetText` now returns the title "Use 40 kg next time?", the body "Full body A will start Leg Press
   at 40 kg.", `keepLabel` "No" and `updateLabel` "Yes". The confirm sheet already puts cancel on the left and confirm on the right.
   Per-set lists still go through `kgSummary` ("25/25/17.5").
5. **Auto-complete.** "Cancel" now reads **Keep going** (same handler and the same `auto-finish-cancel` analytics id). The
   "Volume" row now reads **Lifted** with `toLocaleString('en-US')`, as History does. The delta keeps its old format.
6. **kg per dumbbell.** New `src/kg-label.js` (`kgLabelFor`) matches `/\bdumbbells?\b/i`. I checked the stored values first:
   - library records are saved as `titleCase(equipment)` → "Dumbbell" (130 entries have the free-db value `dumbbell`).
   - the seed `src/db.json` uses "Dumbbells".
   - the exercise editor takes free text.

   It applies to both SetLogForms in `item.jsx`, and to the live workout's set edit, which reads the snapshot item's `equipment`.
7. **"· swapped".** New `views/workout/row-label.js`: `doneRowSuffix` returns " · done" if any set was logged. If every set was
   skipped, it returns " · swapped" when some snapshot item has `replacesItemId` equal to this item's key, else " · skipped".
   `overview.jsx` uses it. No stored field was added. History has no per-exercise skipped label, so it is unchanged.
