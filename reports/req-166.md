## Technical

**1. `scripts/check_handoff.py`**
- `LANE_RE` reads `**Lane: <lane>` from the doc's first lines, so `**Lane: tooling.**` and `**Lane: bug** (small)` both
  parse.
- An unknown value **fails**.
- `classify_tag` returns `decided` for `DECIDED <date> → …` (`->` also accepted). It's terminal: no merge check, and
  NOW.md's "Shipped"/pending cross-check treats it like merged.
- **Warn rule (my call):** an **open** req (READY / NEEDS DECISIONS / BLOCKED / built-not-merged) with neither a Lane
  nor a legacy Gate (`Gate:` or a bold `**[…]**` tag) **warns**. Finished docs (merged, DECIDED, shelved, withdrawn)
  aren't flagged. Measured: 55 of 161 reqs predate Gate tags, and a warning each on every run would be noise. On the
  real repo the warnings are exactly **req-10** and **req-144**, both open and neither naming a lane.

**2. `plan closeout`.** The new step 2b runs **before** the merge:
- It computes the trigger files in `main...<branch>` (the same `REVIEWER_TRIGGER_RE`, tests excluded).
- It reads the req's SHIPPED entry, from its first "Gate" onward, for "reviewer".
- If a trigger file is touched and no reviewer is named → **refuse, nothing merged**, with the override printed.
- `--no-reviewer "<reason>"` (before or after `req-N`; an empty reason is refused) proceeds, and the reason is appended
  to that SHIPPED entry as `No independent reviewer (`plan closeout --no-reviewer`): <reason>`. It's idempotent, and
  the check ignores its own note.
- An **already-merged re-run** keeps the old post-merge warning, because refusing then would block the recovery re-run
  exists for. `reviewer_warning` and its tests are unchanged. `usage` text updated.

**3. `plan status` / `plan save`.** They call `fetch_origin_and_warn` first:
- `git fetch origin`, bounded by `http.lowSpeed*` and `GIT_TERMINAL_PROMPT=0`;
- then a warning when local `planning` **or `main`** is behind its origin copy, with the `git log` to look at.
- Offline or no origin → a note, never a refusal.
- Main is included too: it's the same stale-local risk, at the same cost.

**4. `./check`.** Step 1c runs `scripts/check-cycles.mjs` (**46 ms**). A cycle fails the gate. The green line now
says "no import cycles".

## Workflow

- **Choices the spec left open:**
  - warn on **open** reqs only (the measurement is above);
  - the behind check covers `main` as well as `planning`;
  - a re-run of an already-merged req warns rather than refuses;
  - the SHIPPED check reads from the entry's first "Gate" onward.
- **Seen, not changed:** `check_handoff` run on a **req branch** reports
  `[fail] status: req-N — tagged not-yet-merged, but <sha> already merges it`, because it reads `HEAD`, where the
  branch's own commits look like landing evidence. It's pre-existing (main's script prints the same on this branch),
  and on `main` it's clean.
- For Planner:
  - req-10 and req-144 will warn until they name a Lane.
  - CLOSEOUT.md §The command could mention `--no-reviewer`.
