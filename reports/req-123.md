# req-123 — type tokens, Showcase gaps, dead CSS, tap targets, long names

Branch `req-123` off main 46abf70. Files: `src/ui/ui.css`, `src/ui/Showcase.jsx`, new `src/ui/type-scale.test.js`.

## Technical

**What changed**
- Tokens: added `--ui-text-emphasis: 28px`. `.ui-restpill__time` uses it (same 28px). `.ui-timer__count` uses `var(--ui-text-section)`,
  so 22px where it was 20px (the undefined-token fallback). Updated the token-block comment (was "no ad-hoc font-size values anywhere").
- Deleted `.ui-showcase__row`.
- "Add note" (`.ui-addnote`): the element is `min-height: var(--ui-tap)`. Its own border is transparent, and `::before` draws the
  hairline pill at the old height, `--ui-addnote-h = caption + 2*s1 + 2px` (23px), centred. The negative `margin-block`
  (`(23 - 44)/2`) hands back the extra height, so nothing around it moves (the title row, the overview's Finish stack).
- One more in-gym control was under 44px: the log screen's exercise-name link inside the h1 (26px). It gets
  `.ui-exercise-head .ui-title > a { padding-block: calc((var(--ui-tap) - 1em) / 2) }`. Vertical padding on an inline box
  makes the hit area bigger without changing the line box, so the name renders the same.
- Long names: `overflow-wrap: anywhere` on `.ui-title, .ui-section, .ui-sub, .ui-row`, and `normal` again on
  `.ui-row__value / __action / __chev`. The reset matters because `anywhere` also lowers min-content, which would let a
  flex row squeeze "Start" or "Down" and break them mid-word.
- Showcase: all Button variants + disabled + two `block` buttons, a standalone SectionHeader, NavLink `chevron="back"` and
  `"forward"`, a completed `ui-row--done` row. It reuses req-122's NavLink-looks and Actions blocks, which are not duplicated.
  The variant row uses `<Actions lateral>` where the old class would have gone.
