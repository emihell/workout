# req-127 — exercise names, Restore archived, small routine-editor guards

Branch `req-127`. **[P]**: one new store action, `restoreExercise`. No schema bump and no bulk rewrite. Per DEC-057 it needs the reviewer and the backup reminder before merge.

## Technical

**What changed**
- `src/exercise-names.js` (new, pure): `nameError` (trim; empty → "Name is required."), `exerciseNameMatch` (trimmed, case-insensitive; a live match wins, otherwise the newest `archivedAt`), `routineStartable`, `pickedExercisePath`, and `exerciseFromData`. `exerciseFromData` is the record `store.addExercise` used to build inline, moved here unchanged so the Create-anyway path can be tested.
- `src/storage.js` `restoreExerciseInState`: the inverse of the archive branch of `removeExerciseFromState`, on ONE record. It sets `archivedAt: null`, the normalized shape (`model.js:278`). For an unknown or non-archived id it returns the same `s`. It does not bring back the routine or planned-workout rows that archiving removed.
- `src/store.jsx`: `restoreExercise(id)` calls that reducer. `addExercise` now uses `exerciseFromData(data, uid('ex'))` and behaves the same.
- `Exercises.jsx`:
  - Manual add: inline name error. On Save, a name match replaces the Save row: a live match shows "An exercise called X already exists." with **Use it** / **Create anyway**; an archived match shows "An exercise called X was deleted. Restore brings it back with its history." with **Create anyway** / **Restore**.
  - Search: an archived catalog-name match shows **Restore** instead of Add.
  - Use it and Restore continue to `pickedExercisePath`: the add-to-routine screen for that id in a routine flow, the exercise detail screen in the library.
  - `ExerciseEdit`: an empty name is now an inline error. Before, it silently kept the old name.
- `Routine.jsx`: `RoutineNewForm` (also used by Schedule.jsx:158) and `RoutineEdit` show the inline name error and save the trimmed name. The list hides Start when `!routineStartable`. Up is disabled on the first row and Down on the last.
- `Today.jsx`: `StartButton` returns null for an empty routine. This covers today's block and the upcoming rows.
- Name fields dropped `required`: the browser bubble would have fired before the inline error for `""`.
