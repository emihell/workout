## Technical

**What changed**
- `Today.jsx` TodayEmpty: "Start new workout" is now `<NavLink to="/routines" className="ui-btn ui-btn--primary ui-btn--block">`. The label is kept (unconfirmed, per spec). The unused `go` import is removed.
- `Routine.jsx`: `RoutineNewForm` and `ExerciseFields` take `cancelTo` (a path) in place of `onCancel`. Cancel is `<NavLink to={cancelTo} className="ui-btn ui-btn--secondary">`, which is the old Button's default variant. Callers pass `"/routines"`, `nav.pick` and `parent`.
- `Schedule.jsx:166`: `ScheduleDayAdd` also calls `RoutineNewForm`, so it now passes `cancelTo={dayPath}`. The spec did not list this file, but the caller had to change with the new prop.
- `workout/setup.jsx` WorkoutItemExercise: Cancel is `<NavLink to={backTo} …secondary>`. `backTo` was already the same `itemCurrentPath(…)` target.
- `App.jsx`: the three banners now use `<Banner role="alert">`. `role="alert"` is kept because Banner's default is `status`. Reload is now `<Button>`.
- `history/list.jsx` InProgressHistoryRow: Abandon comes first (on the left) and Continue last (on the right). Variants are unchanged.
- `auto-complete.jsx` is untouched: Edit is still a Button that sets `autoFinishDismissed`.
