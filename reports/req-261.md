## Technical

- **Position** (`src/workout-log.js`). A new private `pillItem(workout)` picks the item: `currentWorkoutItem`, else the first not-done item. Both `workoutPillState` and `workoutPosition` call it, so the pill's item and its N cannot disagree. In `workoutPosition`, N = 1 + that item's index in `counted`. With no open item, or an open item not in `counted`, N = `min(M, done + 1)` as before. `done` and `total` are unchanged. `rest.jsx` follows with no change.
- **Guards.** `ExercisePicker` has `useRef` `committed`, checked first in `add`. That covers `onAdd` and `onPick`, so it also covers the history-pick path into `MidWorkoutPicker`. `MidWorkoutPicker` has its own ref in `commit`, which covers the step's Save and a Swap.
  - A step Save with errors returns before `commit`, so the flag stays unset. Tested: 21, then 4, then tap → one commit with 4 sets.
  - The flag is never reset. Every caller navigates away on commit: Routine add/change, Plan slot, machines Next, workout add and swap. A Back into the picker remounts it, so the flag starts fresh.
- **Ceiling.** `MAX_SETS = 20` and `SETS_RANGE_MESSAGE` are exported from `src/routine-item-parse.js`. They are imported by `mid-workout-pick.js` and `server/plan-build.mjs`. C4's message for every sets refusal is now "sets must be a whole number from 1 to 20 (got X)". `0`, `''` and `2.5` keep their old messages.
- **Choice the spec left open: a blank Sets.** `parseRoutineItem` with a blank Sets counts the reps, kg and duration lists. If there are more than 20 entries, it now gives the same Sets error. Without that, typing 21 reps would get past the ceiling.
