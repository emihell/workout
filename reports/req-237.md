## Technical

**What changed**
- `server/ops.mjs`: `WEEKLY = 'weekly'`, `WEEKLY_KEEP = 4`, `WEEKLY_DUE_DAYS = 7`. `isScheduled(reason)` matches
  `/^(weekly|nightly)(-\d+)?$/`, so `weekly` and legacy `nightly` count together for the age check and rotation.
  `backupDb(..., { scheduled })` (was `{ nightly }`) refuses all four reserved shapes when called by hand.
  `weekly(dataDir, { at, keep, ifDue })` replaces `nightly()`. With `ifDue` it returns `{made:false, newest}` and writes
  nothing while the newest scheduled backup is < 7 days old. Otherwise it backs up and keeps the newest 4 scheduled.
  `listBackups` adds `takenMs`, parsed from the name's stamp (`stampMs`). New pure doctor helpers:
  `scheduledBackupCheck(backups, now)` (≤ 8 days) and `launchdRuns(printText)` → `{runs, lastExit}`.
- `server/ops-cli.mjs`: `backup --weekly [--if-due]`. When not due it prints nothing and exits 0. `backup --nightly` now
  errors with a pointer to `--weekly`. Doctor changes:
  - The any-backup ≤ 26 h FAIL is replaced by the scheduled-backup check. The newest backup of any reason is an `info` line.
  - Checks `<label>.weekly` loaded, prints its `runs` as info, and FAILs only on a `last exit code` that is present and
    non-zero.
  - Checks `<label>.nightly` **not** loaded.
  - Removes `BACKUP_MAX_HOURS`.
- `server/start`: writes `<label>.weekly.plist` (`backup --weekly --if-due`, `RunAtLoad`, `StartInterval 3600`,
  `logs/weekly.log`). Before that, `remove_legacy_nightly` (new in `lib.sh`) boots out `<label>.nightly` if it is loaded and
  deletes its plist. `server/stop` loops over `$LABEL`, `.weekly` and `.nightly`.
- Header and usage text updated in `start`, `stop`, `backup`, `lib.sh`, `ops-cli.mjs`, `README.md`.

**Choices the spec left open**
1. **Age comes from the stamp in the file name, not mtime** (`takenMs`). It is deterministic with `at` injected, and a
   copied or touched file keeps the time it was taken. The old doctor used mtime.
2. **`backup --nightly` is an error now**, not an alias. Deploy runs the old copy's `stop`, which boots the old agent out
   before the new code is in place, so nothing should call it.
3. **Reserved shapes are `weekly`, `weekly-N`, `nightly` and `nightly-N`.** Anything else is allowed, e.g. `weekly-review`
   (tested).
4. **The doctor prints `info  …` lines**: `runs`, and the newest backup of any reason. They are a new line kind next to
   `ok` and `FAIL`, and are never counted as problems.
5. **The doctor checks the weekly agent's last exit code only when the agent is loaded.** "(never exited)" counts as absent.
6. **The weekly log line keeps the nightly line's format** with `weekly:`. Not-due runs write nothing, so the log
   only grows when a backup is made.
