**Name-and-date vs "session": each choice**

| String | Form | Why |
|---|---|---|
| History delete | name · date | the record is in hand |
| History stale/draft Abandon | name · date | in hand; a stale one is from another day |
| Overview/Finish Abandon | name only | it is today's live session; matches the req's example "Abandon Upper Body?" |
| Abandon-on-new warning | "session" | the req's own wording; it is a shared constant with no per-call label |
| `deletionConfirmHead` (exercise/workout delete) | "session" | it is about a reference, with no single session to name |
| Import summary | "sessions" | a count |
| Auto-complete "This session" | "session" | the name is already the title's subtitle |
| Finish "No set in this session was logged" | "session" | the name is in the title |
| Crash screen | "sessions" | generic |
| Home "Start a session" | "session" | it opens the Workouts list, so no session exists yet |
| `abandonInProgress` with no label | "this session" | fallback only |
