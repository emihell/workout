# req-199 — Library goes: /routines is the plain list, with "Your exercises ›" and "Whole plan ›"

Branch `req-199` (off `main` ea47bc6).

## Technical

**What changed**
- **`views/Library.jsx` deleted** (`git rm`), along with its `.ui-library-toggle` CSS. `App.jsx` renders `Routines`, `Exercises` and `Schedule` directly for `/routines`, `/exercises` and `/schedule`.
- **`Routines` (`views/Routine.jsx`):**
  - Back goes to `/`.
  - Each row is a link row (`Row to=/routines/:id`), so tapping the name opens the routine. Start stays as the row's action, and the Edit button is gone.
  - A second `<List>` below the routines holds "Your exercises ›" (`/exercises`) and "Whole plan ›" (`/schedule`).
- **`Exercises` list (no type) and `Schedule`:** both get `<Back to="/routines" />`. Through `showsTodayLink`, both now show the Today link.
- **No route changed.** Every `/exercises/*` and `/schedule/*` route still parses and renders. Child Back targets are unchanged: `/exercises/type/*` and `/exercises/:id` still go back to `/exercises`.
- **History › By exercise › exercise (`history/list.jsx`):** adds "Exercise settings ›", linking to `withFrom('/exercises/:id/edit', '/history/exercise/:id')`. The link is hidden when the exercise is missing or archived.
- Home's "Start new workout" is untouched and still goes to `/routines`.
- No schema change. `workout-mvp-v9` is untouched.

**Choices the spec left open**
- "Your exercises" and "Whole plan" are standard link rows (`Row to`), in their own `List` under the routine list, with no section header.
- Screen titles stay "Routines" and "Schedule". Renaming is req-201.
- The settings link is hidden for an archived (deleted) exercise, which has no settings to edit.
- The link is placed under the title, above the per-routine groups.

**Tests**
- New: `src/req-199.test.js`, 20 tests. They render the whole App under happy-dom and cover:
  - AC1: Home → Workouts → no radiogroup, Start on each row, both rows present, Back to `/`. Exercises and Whole plan each go Back to `/routines` and show a Today link.
  - The name link opens the routine, and there is no Edit link.
  - AC2: an unscheduled routine starts in 2 taps, with `activeWorkout` checked in v9.
  - Route parsing for 9 `/exercises/*` and `/schedule/*` paths.
  - Library.jsx and its CSS are gone.
  - AC3 for both the routine-item path and the History path.
  - No settings link for an archived exercise.
- **No existing test was edited.** All 1452 existing tests passed unchanged after the change.
