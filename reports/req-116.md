## Technical

**What changed**
- `workout-log.js`: new `loggedSetCount` / `anythingLogged` (sets that aren't skipped; a logged warm-up counts) and `autoCompleteArmed` (= `allItemsDone` && !`autoFinishDismissed` && `anythingLogged`). `finishedState` now strips `autoFinishDismissed` as well as `seedOverrides`.
- `overview.jsx`: the summary gate is `autoCompleteArmed(active)`. The mount-local `autoDismissed` state is gone, and Cancel runs `patchActive({ autoFinishDismissed: true })`. The preview branch calls `finishedForPlan(store.workouts, plan)`: once the occurrence is covered it shows "Done {weekdayDate}" and a "View in History ›" link to `/history/:id` in place of Start. `abandonWorkout` moved to `helpers.jsx` so the overview and Finish share it.
- `auto-complete.jsx`: Edit also sets `autoFinishDismissed`. The commit saves `activeFeel`, via `autoFinishArgs`.
- `finish.jsx`: Feel is read from `activeWorkout.overallFeel` (`activeFeel`) and written through `patchActive`. The local `useState` is gone. The set count uses `loggedSetCount`. For an empty workout the screen adds a "Nothing logged." line, Abandon becomes the primary button (with the same `confirm('Abandon?')`), and the save button becomes the secondary "Save anyway".
- `workout-note.js`: new `activeFeel`. `autoFinishArgs` now returns `overallFeel: activeFeel(active)` instead of `''`.
- `storage.js` `workoutSummaryStats`: `sets` = `loggedSetCount(active)`, and the delta now subtracts `loggedSetCount(prior)`.
- `schedule.js`: new `finishedForPlan(workouts, plan)`. It first looks for an exact `occurrenceId` + routine match, then falls back to `coveringWorkout(workouts, routineId, date, slotId)`, the same test Today's Done uses.
- `go()` and `route.js` are unchanged.

**Persisted data:** one optional field, `activeWorkout.autoFinishDismissed`, set only through `patchActive`. It is stripped at finish, so it never reaches history. There is no schema bump and no bulk write. An active workout saved without the field loads, and the gate treats it as not dismissed (unit test).
