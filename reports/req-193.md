## Review fix 5: a down move that can't move says so (code `a8394ea`)

  `movedDown`. `HOLD_REASONS.lightest` = "Already at the lightest weight — kept as is." `(unconfirmed)`
- **Result.** With nothing else moving: action `keep`, reason "Same load. Already at the lightest weight — kept as
  is." If another set does move down: action `down`, reason "Load down. Already at the lightest weight — kept as is."

  `'Alt 4/5'`) reported `down` / "Load down." with the same kg. It now reports `keep` plus the reason. A set below
  the first option also gets the reason; its kg change is fix 3. The reason is saved on the workout but no screen shows
