## Technical

- `plan` `cmd_brief`: `code_dir` is now the first entry of `git worktree list --porcelain`, i.e. the main worktree. It is an absolute path. If `$code_dir/node_modules` is missing, it prints a warning on stderr: `plan brief: WARNING — no deps dir in <path> (run npm ci there first)`. The warning doesn't contain the word `node_modules`, so the count stays 4. The comment keeps the reason for not using `find_worktrees`.
- `plan` `cmd_next`: an awk script replaces `grep -m1`. It reads the `**Next:**` line and the lines after it, up to a blank line or a line starting `#`, `- ` or `**`. It joins them with single spaces and strips the prefix.
- `check_handoff.py`: only the comment of `check_next_line` changed. The rule itself is unchanged.
- Test edits in `plan-guards.test.sh`:
  - The `:201` literal `~/projects/...` became `$CODE/node_modules`, as the spec expected. The same assertion now also checks the warning.
  - `SB` is now the physical path (`pwd -P`). On macOS, `git worktree list` prints `/private/var/...` for a mktemp dir, so the old `/var/...` path would never match.
  - New cases: the multi-line Next (#4, #5, plus a `#` stop), and an extra worktree on branch `scratch`. That case runs brief from inside the extra worktree, with node_modules present so it also covers the no-warning path.
- Choice the spec left open: the whitespace inside the joined Next is collapsed to single spaces, and the ends are trimmed.
