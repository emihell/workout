# req-195 — a workout done today shows in today's block

Branch `req-195` off `main` c2744e3. Code commit `694fef3`. Built by a throwaway build agent.

## Technical

### What changed
1. **`doneInTodayBlock(workouts, slots, todayKey)`** (`src/history-queries.js`, new, pure). It returns today's
   finished workouts (`completedOnDayKey`) minus any that a rendered slot already shows as Done
   (`coveringWorkout(workouts, routine.id, todayKey, slot.id)`). Order is oldest-finished first. The file now imports
   `coveringWorkout` from `schedule.js`. `check-cycles` passed.
2. **`TodayDone`** (`src/views/Today.jsx`, new). It renders `<ul class="ui-today-workout__done">` with one
   `NavLink chevron="forward"` per workout. The text is "<routine> · Done ✓", rendered as "… · Done ✓ ›". Each link
   goes to `withFrom('/history/<id>', '/')`. The name comes from `workoutRoutineName`, as on every other workout row.
   With no workouts it renders nothing.
3. **All three shapes of today's block render `TodayDone`.** `TodayWorkouts` and `TodayHero` show it after their
   slots. `TodayEmpty` shows it **instead of** "Nothing scheduled today.", and "Start new workout" switches from
   `look="primary"` to `look="secondary"` while something is done.
4. **`Today()` computes `done`** with `doneInTodayBlock(store.workouts, others, todayKey)`.
   - `others` is exactly the set of slots that get rendered: all of today's slots when there is no hero, or the
     hero's other occurrences when there is one.
   - The hero rules (`isCurrentWorkout`, `otherTodayOccurrences`, Continue by id) are unchanged.
5. **The list below holds prior days only.**
   - `CompletedTodayRow` and `completedToday.map` were removed from it.
   - `recent` already excluded today's finished workouts by id, and that is unchanged.
   - "No history yet." still checks `completedToday`, so finishing a first workout today doesn't claim there's no
     history.
6. **CSS** (`ui.css`): `.ui-today-workout__done` resets the list style and sets margins s2/s3. Its `.ui-navlink`
   uses `padding: 0` so it lines up flush with the date line. The 44px tap height comes from `.ui-navlink`.

### Choices the spec left open `(unconfirmed)`
- **Wording:** "<routine> · Done ✓" plus a trailing `›` chevron. Per DESIGN §4, a navigation control wears the chevron
  link treatment. "Done" is a status here, not a control verb.
- **Start new workout after a done workout:** `look="secondary"`, still full-width and still in the same place.
- **Order:** done rows come after the day's slots (and after the hero's), oldest-finished first. The old "Completed
  today" list was newest-first.
- **Hero case:** done rows also render inside `TodayHero`. Without this, a workout finished today would vanish from Home
  while another one is in progress, because the list below no longer carries today.
- **Scheduled-and-done slot:** keeps its existing `Done <weekdayDate>` line, which is not a link, exactly as before.
  It is not turned into a "· Done ✓" link.
