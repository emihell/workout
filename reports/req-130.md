## Technical

**What changed**

- `src/library/exercises.json`: the library file (879 entries = 876 free-db + 2 extras + 1 ours). It is **generated** by `scripts/build-library.mjs`, which fetches (or reads) the pinned free-db `dist/exercises.json`, refuses unless the sha256 matches, and applies `deriveLibrary()`. `src/library/PROVENANCE.md` and `LICENSE-free-exercise-db.md` (the Unlicense, copied from the repo's `LICENSE.md` at the pinned commit) sit beside it.
- `src/exerciseLibrary.js` (new) holds everything that's ours: the pin constants, `MUSCLE_GROUPS`, `SEED_ALIASES` (the 22 names by target id), `OWN_EXERCISES` (Hanging Knee Raise, our text), `deriveLibrary`, the lazy `loadExerciseLibrary` (`import(..., { with: { type: 'json' } })`) and `libraryEntryFor`. `catalogNameKey` moved here to avoid an import cycle; `exerciseCatalog.js` re-exports it unchanged.
- `exerciseCatalog.js`: the free-db CDN fetch is gone. `loadExerciseCatalog` = `mergeCatalogs(library, repdb)`; dedupe is still name-only. If the library chunk fails, the RepDB-only list is returned but not cached, so the next open retries (review fix 2). `catalogItemToExercise` adds `libraryId` when the item isn't `repdb-*` (`isLibraryItem`).
- Search scoring (after review fix 1): a whole alias whose `catalogNameKey` equals the query's scores 0, like an exact name. The alias word-split at tier 1 is gone. A partial alias hit scores 2.5, below every partial name hit (2) and above muscle/equipment (3). So aliases add hits after the name hits but never reorder them.
- `exercise-names.js` `patchExercise(ex, patch)`: `store.updateExercise`'s merge `{ ...ex, ...patch }`, moved out unchanged so the rename test is behavioural (review fix 3).
- `exercise-names.js` `exerciseFromData`: copies `libraryId` only when it's truthy, so the key is absent otherwise.
- Credit: `src/views/credits.jsx` `RepdbCredit` renders "Exercise data by RepDB (repdb.co)" linked to https://repdb.co (new tab). It appears at the bottom of Settings and Search. New `ExternalLink` primitive in `ui/index.jsx`: `req-122.test.js` forbids views hand-writing `ui-navlink`, and `NavLink` is hash-routes only.
- `src/exerciseExtras.js` is unchanged. It is now an input to the derive script, and the loader no longer appends it.

**Choices the spec left open**

- **Chunk warning: accepted, not raised.** The library chunk is 1,139 kB (179 kB gzip), above the spec's ~870 kB estimate because of the `photos` URLs. `chunkSizeWarningLimit` is global, so raising it past 1.1 MB would also hide main-chunk growth. The warning now names only `exercises-*.js`.
- Library file shape: pretty-printed JSON with free-db fields first in their original order, then `aliases` (only where present), `muscleGroups`, `photos` (`[]` for extras and ours). Our entries follow the free-db shape (`images: []`).
- Seed aliases are verbatim even where they equal the entry's own name key (Plank, Leg Press, Push-Ups). They're redundant for the resolver but harmless.
- "Library item" means an id that isn't `repdb-*`. Extras and `own-*` save a `libraryId`.
- Credit placement: at the end of each screen. On Search with results, that's below the result list, so it's visible after scrolling rather than always on-screen.
- Hanging Knee Raise: level `beginner`, no secondary muscles (free-db has no hip-flexor value), 4 instruction steps adapted from Hanging Leg Raise.
