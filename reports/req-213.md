# req-213 — a workout done earlier in the week covers its next spot

Branch `req-213` (from `origin/main` 200f98c). Display only: nothing stored, schedule unchanged.

## Technical

**What changed**
- `src/schedule.js` — new pure `doneEarlier(workouts, routineId, date, slotId, schedule)`. It walks the routine's spots in
  the Mon–Sun week of `date` (via `slotsOn`, so one-date moves apply) in date order. Each spot with no `coveringWorkout`
  takes the earliest *unused* finished workout of that routine whose finish date is in `[monday, spot date)`. A workout
  that `coveringWorkout` already gives to any spot that week is not a candidate, and neither is one tagged
  `scheduledFor` a date outside the week. Returns the pick for the asked spot, or null (also null when `slotId` isn't
  on `date`, or the input is empty).
- `src/views/schedule-day.js` — `doneEarlierText(workout)` → `"Done Tue ✓"` (finish weekday, `WEEKDAY_SHORT`).
- `src/views/Today.jsx` — `TodayRoutine`: no cover, but `doneEarlier` returns a workout → a `Done Tue ✓ ›` NavLink to
  `/history/:id` (from `/`), shown in place of Start. Same markup as the existing "Done ✓ — see your sets" line.
  `UpcomingRow`: each name gets ` · Done Tue ✓`. The row stays a single link to the day screen.
- `src/views/Schedule.jsx` — `ScheduleDay` dated row: `earlier` hides Start now, and a `Done Tue ✓` link to the
  session sits as a sub-line (the `ui-moved` caption style). It isn't computed on the undated loop day.
- `src/req-213.test.js` — new, 21 tests: AC1–AC5 pure, plus AC6 rendered as the whole App with `mock.timers` Date
  (Wed Oct 7 / Thu Oct 8 2026).

**Open calls (spec left open)**
- A workout tagged `scheduledFor` a date *outside* the week (e.g. started early from next week's day screen) is never a
  candidate, since it belongs to that date. A tagged workout whose date is *inside* the week but covers nothing there
  (its spot was removed or moved) is a candidate.
- On the day screen the Done line shows on past dated screens too. Start now was already hidden there.
- Home "Coming up": the row is one link (to the day screen), so "Done Tue ✓" is plain text there, not a second link to
  the session. The spec says "linking to that session" in general. Today's block and the day screen link the session.
  A nested link inside the row link isn't valid HTML.
- Today's block uses Home's `todays`, which doesn't filter archived routines. That's unchanged and was out of scope.
