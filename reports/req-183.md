## Technical

- `src/kg-hints.js` (new, pure): `kgHints({ weighted, kg, routineKg, lastKg })` → `{ lastTime, bigJumpFrom }`.
  - A routine kg counts as blank when it is not > 0, the same test `setLogSeed` uses (so `''`, `0` and a missing
    entry are all blank).
  - `routineKg === undefined` means a warm-up (`routineKgFor`'s contract), so a warm-up gets no hints.
  - The typed kg is read with `readKg` (DEC-058 commas).
  - The big-change test is `|kg − ref| / ref > 0.5`, so exactly 50% gets no note. It counts in both directions.
- **History lookup:** `historySetPrefill(last, { setType, workIndex }).weight`. This is the same lookup the seed chain
  used before req-178. It was already computed in `item.jsx` as `historyPrefill`, so no new export was needed.
- `views/workout/item.jsx`: `routineKg` is now computed once and used for both the seed and the new
  `SetLogForm routineKg / lastKg` props. The box's value is still set by the seed.
- `ui/index.jsx` `SetLogForm`: the notes (`ui-field-note`) go right after req-173's note:
  - kg box empty: "No weight entered", or "No weight entered · last time 30 kg" as one line when there is a last-time kg.
  - kg box filled: "Last time: 30 kg".
  - Separately, "That's a big change from N kg" appears live while typing.

## Workflow

- **A choice the spec left open (goes to DEC-102):** "Last time: 30 kg" stays visible once the user types a kg. It does
  not disappear with the box's emptiness. Change §1 conditions it only on the routine being blank. So with routine blank,
  last 30, typed 50, both notes show: "Last time: 30 kg" and "That's a big change from 30 kg". It's easy to hide it once
  a kg is typed if that reads as redundant.
- **Test gotcha (worth an L-):** the fixture loads as legacy `workout-mvp-v8`, and `migrateState` refills an empty
  `suggestedWeights: []` from the legacy baseline (`model.js`, req-120). So a test that blanks a routine kg with `[]` on
  that fixture gets 20/24/24 back. The test uses `[0, 0, 0]` (req-113's "no weight") and sets `DEVICE_FILL_KEY` so the
  req-178 fill doesn't run.
