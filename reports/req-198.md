# req-198 — bar removed; Home is the hub; "Backup & data" under History

Branch `req-198` (off `main` 6080280). Built as changed mid-build by Planner (see Workflow).

## Technical

**What changed**
- **No bottom bar.** `App.jsx` no longer mounts `BottomMenu`. The `.ui-dock*` CSS and the dock tokens are gone. `.ui-main` now clears only the home-indicator safe area (`--ui-bottom-clear: env(safe-area-inset-bottom, 0px)`) plus one spacing step. The picker bar (req-180/181/190) is pinned to `--ui-bottom-clear`. The set-log bar keeps its 22px offset, now named `--ui-bar-bottom`, so it does not move.
- **Home is the hub.** Home has a small "Workouts ›" link (link look) to `/routines`, under the title and above the upcoming list and today's block (`Today.jsx`).
- **"Today" link on deep screens.** The shared `Back` (`views/shared.jsx`) renders "Today" right-aligned in the same row (`.ui-back-row`). The rule is the pure `showsTodayLink(backTo, routeName)` in `route.js`: shown when Back's target (query dropped) is not `/`. It never shows on `today` or on any `workout*` route.
- **The Workouts list gets a Back to `/`.** The Library wrapper (`/routines`, `/schedule`, `/exercises`) now renders `<Back to="/" />` above its toggle. History keeps its Back to `/`.
- **History:** a "Backup & data ›" row (`/settings`) is always the last thing on the screen, zero workouts included. With no months, the empty month `<List>` is no longer rendered, so its hairline doesn't stack on top of the Backup row's.
- **`/settings` → "Backup & data".** Back goes to `/history`. Export and Import come first. Below them is a `Developer` section: Assistant prompt, Export analytics, Feedback notes, Components ›.
- **Save-failed banner:** the copy is now "…export a backup now." and the banner has an **Export** button. A new `exportBackup(store, opts)` in `import-backup.js` is the one Export path; Backup & data and the banner both call it.
- **First-run Home:** the Schedule and Settings rows are dropped. Routines, History and Import stay.
- The Showcase banner sample copy now matches the new banner copy.

**Choices the spec left open**
- The Today link is plain text ("Today", link look, no chevron), in the Back row's right slot.
- Home's link is labelled "Workouts ›" (Planner's wording). It links to `/routines`, which still reads "Routines" until req-201.
- `Developer` uses the existing `SectionHeader`. Assistant prompt stays a checkbox that changes what Export includes; it now sits apart from the Export button.
- The banner's Export always exports without the assistant prompt.
