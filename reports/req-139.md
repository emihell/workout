# req-139 — library polish: display names, missing staples, library-only search, common first

Branch `req-139` off `main` @ 3bb2585. Not merged.

## Technical

**What changed**
- `src/library/common.js`: new `DISPLAY_NAMES` (97 entries), folded in as own-field `displayName`. I dropped 100 stored
  aliases that repeated their own entry's display name by key, using a script, not by hand (e.g. "Bench Press", "Push-Ups",
  "Lat Pulldown"). Added 15 tag rows for the new own entries. `own-fan-bike` gets the alias "Air Bike" (it shadows free-db's crunch).
- `src/library/own-exercises.js`: 15 new `own-*` entries with legacy fields and 3 instruction lines each (req-138 rewrites the text).
- `src/exerciseLibrary.js`: `displayName` added to `OWN_FIELDS`, and to `NEW_FIELDS` (so a non-common entry can't carry it).
  `shownName()`. `COMMON_COUNT_RANGE` → 170–200. `libraryProblems` key rules rewritten: a key on a common entry may shadow
  a **non-common name** only; every other clash fails; so do "display name equals its name", "alias repeats its display
  name" and an empty display name. Resolver: `libraryId` → name → displayName → alias → null. The name comes before the
  display name, so a stored free-db name always resolves to its own entry.
- `src/exerciseCatalog.js`: RepDB fetch, `fromRepdbItem`, `mergeCatalogs` and `isLibraryItem` are gone.
  `loadExerciseCatalog` = library only. A failed load throws "Could not load.", nothing is cached, and the next open
  retries. Search scores the shown name on the name tiers. When a displayName exists, free-db's name counts as an alias
  (exact 0 / partial 2.5), and the sort key is the shown name. New `searchCommonFirst(list, q, 25)` →
  `{ common, rest, restCount }`. `catalogItemToExercise` saves the shown name, plus `libraryId` for every item.
- `src/exercise-names.js`: `libraryItemMatch(exercises, item)` matches by libraryId, then displayName, then name. Live
  beats archived across all three tiers; among archived, the first tier that has one wins, newest first.
  `exerciseNameMatch` is unchanged.
- `src/views/Exercises.jsx`: common rows first, then the "Show N more from the full library" button (quiet, block). It
  resets on every keystroke. With no common hit the rest shows directly. The RepDB credit is removed. `credits.jsx` and
  `PROVENANCE.md` comments are updated. Settings still shows the credit.
- `scripts/screenshot.mjs`: `--type "<text>"` types into the first visible text field. It runs in argv order with `--click`.
- `src/req-139.test.js` (new, 50 tests).

**Choices the spec left open**
1. **`searchExerciseCatalog` still returns the flat ranked array. The split is a new `searchCommonFirst`.** The spec says
   `searchExerciseCatalog` returns `{common, rest}`. That would break unedited tests that index `[0]` on it
   (`exerciseCatalog.test.js` "ranks name matches…", "local extras"; the fixtures have no `common`). Those tests would
   need edits the spec doesn't sanction. Behaviour is as specified. The 33 receipts are also asserted on what Search
   shows first (`req-139.test.js` "shown first: …").
2. **The name exact tier matches on the name key too** (`catalogNameKey(shown) === catalogNameKey(q)`). Dropping "Pull Up"
   (same key as display name "Pull-Up") had pushed "pull up" → Pull-Up down to tier 2, behind Assisted Pull-Up
   (measured: the receipt failed). The key match restores the dropped alias's exact hit. The receipts and the
   press/row/machine top-10 hold.
3. **"Never equal to name" is a literal text comparison, not a key comparison.** "Pushups" → "Push-Up",
   "Band Assisted Pull-Up" → "Band-Assisted Pull-Up", "Glute Ham Raise" → "Glute-Ham Raise" share a key with their
   free-db names and are still real cosmetic fixes.
4. **"Every common entry has displayName" is read together with "set only where the free-db name isn't already clean".**
   So 97 of 178 common entries have one. The other 81 are already clean (Face Pull, Leg Press…) or are own-* (named by us).
   Every common entry's **shown** name is unique by key (tested).
5. **Resolver order is name → displayName.** When a display name shadows a non-common name, the non-common entry wins in
   the resolver. No display name does that today: the only shadowing key is the alias "Air Bike" (measured).
6. **The 5 extra staples:** Pendlay Row, Hollow Body Hold, Suitcase Carry, Wall Sit, Cossack Squat. Tibialis raise was
   rejected because the tree has no tibialis (deliberate, req-133).
7. Families: Landmine/Z press → fam-overhead-press; Pendlay/Meadows/Seal → fam-row; single-leg RDL →
   fam-romanian-deadlift; Belt/Pendulum → fam-squat; Cossack → fam-lunge; Bayesian → fam-curl; Suitcase →
   fam-farmers-walk; Bird Dog → fam-dead-bug; Copenhagen, Hollow and Wall Sit have their own families. Landmine press is
   `unilateral: false` (done with one hand or both).
