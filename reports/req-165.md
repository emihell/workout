## Workflow

- **The one behaviour change (reviewer-found; kept by Planner, DEC-088).** I missed it and the reviewer caught it. On
  main, `setsForItem`'s `set.sessionItemId === item?.id` was `undefined === undefined` for a snapshot item with **no
  `id`**, so every set counted as that item's. That item shape comes from a legacy-migrated in-progress or draft
  workout: neither migrateState path adds an `id`, and db.json's snapshot items have none. The effects were that every
  item read done, auto-complete armed, and Finish wrote no skipped sets. With the `session*` fallback removed, each item
  shows its real state and Finish records the unlogged sets as skipped. It only matters for an in-progress workout
  saved before v9. **Receipts** (follow-up commit):
  - The golden now also covers **Finish**, the path that writes history. `scripts/req-165-golden.mjs` re-recorded
    main's output at `dd06a01` (unchanged base) and added an in-progress workout of today's shape (items with ids) to
    the v9 doc.
  - The v9 finish is deep-equal to main (12 skipped).
  - The id-less v8 finish is deep-equal to main except that workout's sets: main has 2 logged and 0 skipped, the branch
    has the same 2 logged plus 13 skipped.
  - A DEC-088 pin (`finishedState(migrateState(old v8))` gives 13 skipped, computed independently as each item's
    warm-up + work sets minus its logged ones) is **red on main** (`expected: 13, actual: 0`) and green on the branch.
- **Wording change (Planner: fine as is):** The exercise delete confirm no longer ends
  "…from N routines (and any planned workouts)", because deleting no longer touches plans. The routine confirm's
  "N planned workouts" part only ever showed for a doc with a stale plan. Everything else is unchanged; the smoke, the
  golden and the analytics comparison are the receipts.
- **Added scope, cheap:** `--deny-warnings` on lint, so 0 stays 0 (a planted warning → exit 1).
- **Not touched (handoff/, read-only to me):** BACKLOG's "Current shape" drift (F-DRIFT-6's last bullet) and
  `reference/schema.md`. Both are Planner's, from the list above.
- The browser scripts misfired a few times before they were right: a textless dock link, and "Save anyway" on an empty
  Finish. Both were script bugs; the analytics receipt is from the final, full 9-step run on both builds.
