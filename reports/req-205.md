# req-205 — Home: 6 days forward with rest days, no title, no gap (+ DEC-115: Schedule › / History under Schedule)

Branch `req-205` (off `main` 5ef58bc). Code commits `bc47f17` (DEC-114 scope) and `f736c50` (DEC-115 scope, added mid-build by Planner).

## Technical

**What changed**
- **`schedule.js`:** `upcomingWorkouts` is replaced by pure `comingDays(schedule, routines, today, n = 6)` → `[{dateKey, week, weekday, slots}]`, the next `n` calendar dates after today, nearest first. `slots` holds only active (present, not archived) routines and is empty on a rest day. It is loop-aware through `slotsOn`/`loopWeekIndex`.
- **Home (`views/Today.jsx`):**
  - "Coming up" always has 6 rows, furthest first: `Thu, Oct 15 · Lower Body ›` or `Wed, Oct 14 · Rest ›`. A Rest row has `ui-row--rest` (muted label). Every row links `/schedule/W/D?date=…&from=%2F`, and none has Start.
  - The visible `<Title>Today</Title>` is gone. A `<h1 className="ui-visually-hidden">Today</h1>` stays.
  - The whole column ("Week x of y" in a longer loop, "Workouts ›", Coming up, today's block, the stale Continue row, the last row) is one `.ui-home-bottom` block. `.ui-home-top` is deleted. Spare space goes above "Workouts ›".
  - DEC-115: the last row is **"Schedule ›"** (`/schedule`). It was "History ›".
- **`ui/ui.css`:** adds `.ui-row--rest .ui-row__label { color: var(--ui-ink-2) }`. The req-204 flex/min-height/`margin-top: auto` rules are unchanged; only the comment was updated.
- **DEC-115:**
  - `Schedule` Back is `/` (it was `/routines`), so it has no Today link. A "History ›" row sits at the bottom, below the plan.
  - `History` Back is `/schedule` (it was `/`), so it now shows the Today link. History's contents are unchanged.
  - The Workouts list's "Whole plan ›" row is removed.
  - Every other `/history` and `/schedule` Back was grepped. The detail's `from` still wins, so Home's done link returns Home.
- No schema change, and nothing writes stored data.

**Choices the spec left open**
- **No schedule at all → 6 "Rest" rows.** "Coming up" no longer hides, because DEC-114 says every day is shown. req-204 AC5 hid it.
- **The "Coming up" header was kept.** It sits inside the one block, and the gaps measure ≤ 24 px.
- **"Week x of y" (loop > 1) was kept.** It is now the first line of the block, above "Workouts ›". It sat under the old title.
- **First-run Home is unchanged.** It keeps its visible "Today" title and its "History" row. The req's scope is the normal Home.
- A day whose only workouts are archived or missing reads **Rest**.
