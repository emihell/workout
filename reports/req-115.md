  `programs`, `workouts`, `plannedWorkouts`, `draftWorkouts`, `schedule.slots` must be a plain object;

  `activeWorkout` null/absent or a plain object passing the workout check. `state` must be a plain object
  (was `typeof 'object'`, so an array passed). Absent fields stay fine (req-39 rule).

- `storage.js` `loadState` — a parsed value that is not a plain object (`"x"`, `[1,2]`, `42`, `null`)
  throws into the existing DEC-032 catch: unreadable latched, saves held, v9 and legacy keys untouched.
- `App.jsx` — outer `ErrorBoundary` around `StoreProvider` (the existing component, unchanged); the inner
  one around `<Screen/>` stays.
