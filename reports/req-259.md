## Technical

- `scripts/qa.mjs`: start's argument loop moved into the exported `parseStartArgs(args, { root })`. It is pure (no fs, no
  build), so the test runs without vite. `--empty` plus `--seed` throws `--empty and --seed are exclusive` before
  `stop()`, `mkdtemp` and the build. `main()` adds the `plan qa: ` prefix, which gives the exact line the spec asks for.
  `prepareDist(dist, { empty, seedJson })` calls `injectSeed` unless `empty` is set. The state file now stores `empty`
  next to `seed` (`seed: null` when empty). `seedLabel()` builds the `seed: <file>` / `seed: none (--empty)` text for the
  start line and for `status`. An old state file without `empty` still reads as `seed: <file>`. A trailing `--seed` with no
  file now refuses with `--seed needs a file`. Before this change it resolved `undefined` and threw a less clear error.
- `plan`: two usage lines changed, in `plan help` (the `plan qa` entry) and in `cmd_qa`'s usage. Nothing else in `plan`
  changed, because `cmd_qa` already passes `"$@"` through.
- `src/req-259.test.js` (6 tests): the "no seed script with --empty" guard, the default still seeded, defaults and
  `--node-modules`, the refusal in either order, unknown argument and missing ref, and `seedLabel`. It sits under `src/`
  because `./check` only collects `src/**/*.test.js` and `server/**/*.test.mjs`. There were no existing qa tests to extend.
- `scripts/smoke.mjs` is untouched. It still imports `injectSeed`, which is still exported.
- **Open choice — what "localStorage is empty" means:** with `--empty`, the origin has no `workout-mvp-v9` or `-v8` after
  the first load or after a clear + reload. The app itself still writes its own side keys on load:
  `workout-routine-kg-filled`, and `workout-mvp-analytics` on the first load. The served HTML writes nothing. I read the
  criterion as "no workout document" and did not change the app.
- **Open choice — the start line wording:** `serving, seed: none (--empty) — the origin starts empty:`. With a seed, the
  existing line is kept with its `seed: <file>` form: `serving, seed: <file> under workout-mvp-v8:`.
