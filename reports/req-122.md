## Technical

**What changed**
- `src/views/nav-look.js` (new, plain JS): `lookClass(look, block)`. `'link'` → `ui-navlink`;
  `'primary'|'secondary'|'quiet'` → `ui-btn ui-btn--<look>` (plus ` ui-btn--block` when `block`); anything else
  (`undefined`, `'plain'`) → `''`. Same class order as `Button`.
- `src/views/shared.jsx`: the base NavLink takes `look` and `block`, joined ahead of any `className`. With no look it
  adds no class, so BottomMenu (which uses the base) is unchanged. `Back` → `look="link"`. `ExercisesLink` →
  `look="link" chevron="back"` with the label `Exercises` (before: the label was a hand-typed `‹ Exercises`).
- `src/ui/index.jsx`: the library `NavLink({ look = 'link', ...rest })` wraps the base; `Row` still gets
  `ui-navlink ui-row__link`. New `Actions({ retreat, lateral, forward, className })` renders
  `<div className="ui-actions …">{retreat}{lateral}{forward}</div>`.
- Views: every NavLink now imports from `ui/index.jsx`, and nothing hand-writes a class on a link.
  `className="ui-navlink"` is dropped (it's the default look). `className="ui-btn ui-btn--X"` → `look="X"`. Today's
  link → `look="primary" block`, overview Finish → `look={allDone ? 'primary' : 'secondary'} block`. The in-text
  exercise-title link (item.jsx:68) had no class, so it gets `look="plain"` to stay classless.
- 13 `.ui-actions` rows → `<Actions>`: set-edit, Routine ×3, Schedule, Exercises ×2, history/edit and setup
  (retreat Cancel + forward Save); recalc (retreat Skip + forward Apply); replace (retreat only); Settings (lateral:
  Export, Export analytics, Import); item.jsx (`className="ui-exercise-actions"`, lateral: Remove set / Skip exercise /
  Replace exercise). The req count said 12. The 13th is item.jsx's `ui-actions ui-exercise-actions`.
- Showcase: new blocks "Nav link — button looks" (primary / secondary / quiet / primary block) and "Actions"
  (Cancel · Skip · Save).

**Choices the spec left open**
- API: `look` = `link` (default) | `primary` | `secondary` | `quiet` | `plain`. I added `plain` (no library class)
  for the in-text title link. `block` applies to button looks only. `Actions` takes props only (`retreat` / `lateral`
  / `forward` / `className`); pass a fragment for several nodes in one slot. There is no ordered-children form, so
  order can only come from the component.
- The base NavLink stays in shared.jsx as the building block. Merging it into ui/index.jsx would have made shared.jsx
  (Back, ExercisesLink) import ui/, which creates a cycle. BottomMenu keeps importing the base.
