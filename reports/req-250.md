# req-250 — every closeout ends at a clean point, printed by code

## Technical

- `plan` `cmd_next`: the final branch ("both worktrees clean, planning fully published") now also prints
  `CLEAN POINT — good time to /clear. Then paste:` and `  Planner: resume from handoff/NOW.md (Next: <text>)`.
  `<text>` is the first `**Next:**` line of `main:handoff/NOW.md` with the prefix stripped. No other branch prints it.
  If NOW.md on main has no such line, it prints `(NOW.md on main has no **Next:** line — add one)` in the text's place.
- `scripts/check_handoff.py`: new `check_next_line` (finding `next`, severity `fail`). NOW.md must have exactly one line
  starting `**Next:**`. Zero lines fail, and two or more fail too. A missing NOW.md is skipped, the same as the size check.
- `.claude/skills/closeout/SKILL.md`: step 7, "run `./plan next`; end your message with its output, verbatim".
- Tests: `scripts/plan-guards.test.sh` has 3 new `next` cases in its scratch two-worktree repo: clean (CLEAN POINT),
  dirty planning (none) and unpublished planning (none). `scripts/check-handoff.test.sh` has 3 new cases: missing → 1,
  one → 0, two → 1.

## Workflow

- **Test edits (fixtures, not assertions):** NOW.md fixtures in `check-handoff.test.sh` (4 layouts), `check-lanes.test.sh`
  and `plan-guards.test.sh` (the initial NOW.md, plus the 50-line save case, now 49 lines + a `**Next:**` line) gained a
  `**Next:**` line. Without it, their "clean → exit 0" assertions fail on the new check rather than on what they test.
  No assertion was weakened.
- **Merge order matters:** on this branch the real NOW.md has no `**Next:**` line. So `check_handoff` exits 1 and
  `./plan status` reports drift (`[fail] next: …`) until planning's NOW.md change lands. `plan save`/`publish` only
  warn. Merge it with, or after, the NOW.md `**Next:**` line.
- Open choices I made: (a) more than one `**Next:**` line fails too ("exactly one" in the spec); (b) a missing NOW.md is
  not reported by this check; (c) `plan next` still prints CLEAN POINT with a placeholder when the line is missing, so a
  clean state is never hidden.
