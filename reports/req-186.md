## Technical

**What changed**
- `src/workout-log.js` — new pure helpers: `setListRows` (done/current/upcoming rows, plus a `highlighted` flag),
  `loggedSetRowText`, `currentWorkoutItem`, `itemSetPosition` (the counting `setProgressLabel` used, warm-up
  included, clamped to M), `restClockText` (`45s` / `1:12`), `workoutPillState`. `setPreview` takes an optional
  `workLogged`. When it's given, upcoming work rows get the same `carryForSet` the form will apply. Without it,
  nothing changes (setup.jsx still calls it that way).
- `src/views/workout/item.jsx`
  - Previous now sets the view state `viewIndex` (an index into `active.sets`). It no longer calls `removeActiveSet`
    and no longer writes a draft. While a set is being viewed, a second `SetLogForm` (`viewing`) shows that set's
    logged values (`setDraftFromLoggedSet`). Its bar is Previous (if an earlier logged set exists) · Next
    (secondary). After any edit the forward button becomes Save (primary). Save goes through
    `liveSetEditPatch` → `store.updateActiveSet`, then back to the current set.
  - Leaving the current set flushes its pending draft, and Next re-reads it, so typing on the current set survives a
    Previous/Next round trip.
  - `WorkoutItemLive` is keyed by item, so view state doesn't leak when the pill opens another item.
  - The set list (`ul.ui-setpreview`) renders for the whole exercise. The highlighted row gets
    `aria-current="step"`. The title's N/M is gone.
- `src/views/workout/rest.jsx` — `WorkoutPill` replaces `RestPill`. A tap does `go(itemLogPath(...))`. `go()` is
  already a no-op when the hash is unchanged.
- `SkipRest` — a quiet button that makes the same write as the old pill tap. It is shown only while resting, in the
  log screen's lateral row.
- The pill is swapped on all 7 screens (overview, log, done, set-edit, replace, setup, finish).
- `src/ui/index.jsx` — the presentational `WorkoutPill` (lead · separator · "set N/M"). `SetLogForm` gains
  `viewing`/`onNext`. "Edited" means any field was touched (a `useState` flag). Enter on an unedited viewed form
  acts as Next.
- `src/ui/ui.css` — `.ui-restpill--go` uses a pulsing halo plus a fill "breathe", grayscale per DEC-017. Under
  `prefers-reduced-motion` it is a static double ring instead.
- `.ui-restpill__set` is body size and bold (F9).
- Set-list row styles: tick column, `.is-here` fill and bold.
- `.ui-visually-hidden` is new.
- `src/views/workout/rest-countdown.js` — returns `now` too and ticks once when the effect starts. Without that
  tick, a rest armed long after mount showed a stale, inflated time for 250 ms.
- `src/views/set-values.js` — `liveSetEditPatch`.
- No new persisted field. Save writes only `sets[i]`. `restEndsAt` / `restPausedRemaining` are never written by
  Previous, Next or Save.

**Choices the spec left open** (each `(unconfirmed)` for Emilio)
- Under a minute the pill reads `45s · set 2/3`; from 60 s it reads `1:12 · set 2/3`.
- The separator "·" is a visible span, hidden from screen readers.
- Accessible name: "Rest 1:12, set 2/3 — open the exercise" / "Go, set 2/3 — open the exercise".
- GO is grayscale (DEC-017 forbids hue): a pulsing halo ring plus a fill darken/lighten, 1.4 s. Emilio said
  "glowing/changing colors". If he wants real colour, DEC-017 needs revisiting.
- "Edited" means any field was touched, even if changed back. The spec's "if a field was changed" is read loosely.
- While viewing a logged set:
  - the list highlight moves to that set, and the title meta reads "Set 1 · logged" (or "Warm-up set · logged");
  - "Add note" and the note field are hidden (a note is editable via set-edit);
  - Skip exercise, Swap, Remove set and Skip rest stay.
- Save does not update `seedOverrides`, so an edited earlier kg does not re-seed the later sets.
- Saving an edit over a *skipped* set writes the new values. `isSkippedSet` reads `reps` only, so once reps are
  typed it counts as logged. Its stored `note: 'skipped'` stays. This edge case is `[inferred]` and was not run.
- The current row of the list shows the prefill rule, not the live draft typed into the form above it.
- "Skip rest" goes first in the lateral row under the list, not near the top: kept away from the pill and Back.
- "Nothing logged yet" means `workout.sets` is empty. A skipped set counts as progress, so after Skip exercise
  the pill shows the first not-done item.
