## Technical

**Guard 1 — `plan ping req-N` (new read-only subcommand).** `plan:cmd_ping`.
- Resolves the req doc exactly as `closeout` does (file form `handoff/work/req-N-*.md`
  first, then folder `.../req-N-*/README.md`) from the planning worktree; reuses the same
  "not a requirement id" and "no requirement doc …" refusals.
- Refuses unless **both**: the doc exists on main (`git cat-file -e main:<relpath>`) **and**
  planning is fully published (`git log main..planning` empty — the same signal
  `plan status` prints). On refusal it lists every missing reason and points to
  `./plan publish`. This is the line that would have caught R1/L-019.
- On success prints a ready-to-paste ping (branch `req-N`, the on-main spec path, and the
  1/2/3 handover shape from PLANNING.md). Sends nothing — `plan ping` can't; SendMessage is
  a Claude tool. Read-only: no add/commit/merge/push.
- Wired into the dispatch alongside `status`/`next`; usage block updated.

**Guard 2 — blocking NOW.md ≤ limit in `plan save`.** `plan:cmd_save`.
- Before `git add -A`, if `handoff/NOW.md` exceeds the limit it refuses (exit 1, nothing
  staged, working tree untouched) naming the count. Placed before staging so `git status`
  still shows NOW.md modified/unstaged.
- The limit is **read at runtime** from `check_handoff.py` (`now_md_limit()` imports
  `NOW_MD_RULE_LIMIT`; the module is import-safe — all work behind `__main__`), never a
  second hardcoded 50. Working-tree count uses `wc -l`, which matches `check_handoff`'s
  git-object `line_count` (both count newlines, both one short on a missing final newline —
  so the two never disagree).
- The existing **post-commit** drift surfacing (req-46 #1) is untouched; only the NOW.md
  working-tree count now blocks up front. `check_handoff.py` classification unchanged.

**Verification (receipts):**
- Real repo (safe, read-only): `./plan ping req-99` → prints ping, exit 0;
  `./plan ping req-99999` → "no requirement doc", exit 1; `./plan ping foo` → "not a
  requirement id"; `./plan ping` → needs a requirement.
- `scripts/plan-guards.test.sh` (throwaway two-worktree sandbox, copies real

  - ping refuse: doc uncommitted in planning worktree though planning published
  - save refuse at 51 lines → exit 1, no new commit, NOW.md still modified/unstaged, names
    "51 lines"
  - save at exactly 50 lines → commits normally
  Output: `plan-guards: all checks passed.`
