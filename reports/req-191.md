## Technical

### What changed
1. **Body-part search** (`exerciseCatalog.js`).
   - `muscleGroupForQuery` maps a query to a group. It accepts the `MUSCLE_GROUPS` names in lower case, plus these synonyms: arm, leg, shoulder, abs, ab, abdominals, stomach.
   - `groupStaples` returns the group's listable staples (`muscleGroups` includes the group). They are ordered machine/cable first, then free, then bodyweight, then cardio, A→Z within each.
   - `searchCommonFirst` puts every group staple first, then today's staple hits, which are capped at `limit`. `rest` / `restCount` are unchanged.
   - The old body is now the private `searchCommonFirstByName`. Both callers (`ExercisePicker.jsx`, `Exercises.jsx`) go through it unchanged.
2. **No countdown after a skip.**
   - `endedOnSkip(workout)` (`workout-log.js`) is true when the newest set record `isSkippedSet`. It is derived and stores no field.
   - `overview.jsx` passes `countdown={!endedOnSkip(active)}` to `AutoCompleteSummary`.
   - With the countdown off there is no interval and no "Finishing in". The buttons are [Finish] (primary; the same `commit` the countdown would run) and [Keep going] (quiet; the same dismiss as before). Edit is not shown.
3. **Tap a done set row** (`item.jsx`).
   - A done row's content is now a `button.ui-setpreview__tap`. It calls `openLoggedSet(setIndex)`, which flushes the current set's draft and sets `viewIndex`, the same view state Previous uses.
   - Upcoming and current rows are not buttons.
   - CSS keeps the row's look.
4. **Plain days.**
   - `planDaysText(weekdays, today)` (`plan-templates.js`) returns "Starts today (Tue), then every Tue and Fri", or "Every Fri" for a workout that doesn't include today.
   - `WEEKDAY_SHORT` moved there from `Plan.jsx`.
5. **The Add step is prefilled** (DEC-107 §1).
   - `setupDefaults(pick)` (`mid-workout-pick.js`) reads the pick's own starting plan (`pickerItem`). A reps or timed exercise gets 3 sets and 90 s. A cardio exercise gets 1 set and a blank rest.
   - `mid-workout-picker.jsx` seeds the step with it. The intro line is reworded.
   - Swap is unchanged.
6. **Reps carry** (DEC-107 §2).
   - `carryForSet` also returns the reps of the same source set: the last non-skipped working set this session (`carriedWorkingSet`).
   - `setLogSeed` now sets `reps: target || carry?.reps || ''`.
   - A warm-up gets no carry (`carryForSet` → null). A stale override `reps` is still never read.
7. **Small items.**
   - Routine names are now "My workout" and "My workout A/B" (`machinesPlan`).
   - The stat now reads "Total lifted (all sets added up)".
   - The picker button reads "Add" (disabled) with nothing ticked, and "Add N" otherwise. This is the `ExercisePicker` default and `add.jsx`.
   - New `SearchField` (`ui/index.jsx` + CSS): a 44 px × that shows only while the field has text. It is used by `ExercisePicker`, so routine add, plan slots, machines-first, and mid-workout Add/Swap all get it.

### Choices the spec left open (all `(unconfirmed)`)
- **Group words.** The six group names plus arm, leg, shoulder, abs, ab, abdominals and stomach. Muscle words such as "lats" and "biceps" are not group words and keep today's search.
- **Equipment order.** machine/cable → free → bodyweight → cardio, A→Z inside each. Rowing Machine (cardio) sorts last under Back.
- **Group size.** A group search shows **all** of the group's staples (Legs has 72), then up to 25 more staple hits. The 25 cap no longer bounds the first tier for a group word.
- **"Last change was a skip"** means the newest set record is skipped. A set-level Skip of the very last set also gives the no-countdown summary.
- **[Finish] commits immediately.** It does not open the Finish screen, and there is no Edit on that summary; Keep going → the overview's Finish link reaches it. It uses the same analytics id and beep as the auto-commit.
- **Reps carry source.** Same as kg: the last *non-skipped* working set. Set 1 logged 10, set 2 skipped → set 3 starts at 10. Set 1 skipped → blank.
- **Cardio on the Add step.** A cardio pick prefills 1 set and a blank rest (DEC-097 §4's cardio plan), not 3/90.
- **A/B day text.** Each workout gets its own line: "Starts today (Tue), then every Tue" / "Every Fri".
- **The × leaves ticks in place.** It clears only the query and "show more".
