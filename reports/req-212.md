## Technical

**What changed**

- `ui/index.jsx`
  - `SetLogForm`: the effort caption + four buttons, Previous, Next and the whole `viewing` mode are gone. Every set
    (warm-up, work, cardio) gets a quiet **Skip set** row over one primary **Done**. Enter submits too. `onComplete`
    now gets `{ weight, reps, durationSec }` (+ `cardio`), with no `effort` key.
  - New library parts, all in the Showcase:
    - `ExerciseHead`: the old ad-hoc head markup, now a component.
    - `SetList`: the old ad-hoc `ui-setpreview` list.
    - `SetEditSheet`: a bottom sheet with the set's own fields (kg + reps, `Duration (s)` on a timed set, or the cardio
      fields), plus Cancel / Save. It validates like the set form. Backdrop and Escape cancel.
- `views/workout/item.jsx`
  - Done stores `rpe: null`. Done and Skip set both store `loggedAt: new Date().toISOString()`.
  - A done row opens `LoggedSetSheet` (wraps `SetEditSheet`). Save goes through the existing `viewedSetSave` →
    `store.updateActiveSet` (+ the seed-override rerun), so the rest timer is untouched and `loggedAt` is never patched.
  - `WorkoutItemDone` is now the **exercise review**. It shows:
    - the name and each set line (tap → the same sheet);
    - the ↑ N% line (`exerciseImprovementPct`, the overview's helper);
    - **Effort** (`SegmentedControl`, `EFFORT_OPTIONS`, nothing preselected);
    - **Next: {exercise}** / **Finish**, **Choose exercise**, **Add set** (quiet).
  - The last Done (and the plannedDone fallback effect, and Remove set when it completes the item) now lands on the
    review. The routine-kg confirm's `stayOn` is now the review path.
  - The ad-hoc `ui-item-note` class went (now plain `ui-sub`). The note stays under the title.
- `workout-log.js`: new pure helpers, unit-tested.
  - `itemEffortSets`: this item's logged work sets that are not skipped.
  - `withItemEffort`: writes `rpe` on exactly those sets.
  - `itemEffort`: the shared 2/3/4 value, or `''`.
  - `nextNotDoneItem`.
- Wiring: `state-reducers.js` `itemEffortState` → `store.setItemEffort(itemId, rpe)`.
- `ids.js`: `EFFORT_OPTIONS` = Easy 2 · Medium 3 · Hard 4. `RPE_OPTIONS` keeps 5 for reading old sets.

**What depends on the shared code, and whether it still holds**

- `withLoggedSet` is unchanged. `loggedAt` is a new optional set field:
  - `migrateState` keeps unknown set fields;
  - export/import keeps it (AC7);
  - Finish's skipped fill records carry none (asserted in req-175).
- `updateActiveSet` is unchanged.
- The History set edit (`set-edit.jsx`, `views/history/*`) is untouched. It still edits rpe per set and shows "Failure".

**Choices the spec left open**

1. **"Next" order.** It picks the next not-done exercise after this one in list order, wrapping to one earlier in the
   list (skipped past).
2. **Finish target.**
   - If the auto-complete summary is armed: go to the overview, which shows it (what the last Done reached before).
   - Otherwise (summary dismissed earlier): go to the Finish screen.
3. **Effort is clearable** (review round 1): a leading "—" segment takes it back to none (rpe null on those sets).
4. **Effort is hidden** on cardio and when the item has no logged, non-skipped work set (warm-up-only or all skipped).
5. **Effort after Add set** (review round 1): a work set logged on an item that already has a picked effort gets that
   effort, so the review keeps showing it. A fresh exercise still logs `rpe: null`.
6. **Effort and an un-skipped set.** Editing a skipped set into a real one on the review re-applies the picked effort
   to it.
7. **Review set lines** use the set list's shape (`1 · 30 kg × 12`, `loggedSetRowText`), not `formatSetLine`. So the
   per-set effort word ("· Medium") no longer shows on those lines; the effort shows once, in the control.
8. **The review shows equipment and the routine note** under the title, as the old done view did (restored in review
   round 1).
9. **A marked-done item's log route** now redirects to its review, not the overview. This was needed: otherwise the
   effect could override `finishExercise`'s navigation to the review.
10. **Sheet field details.** The timed-set field is a plain `Duration (s)` number box. Reps are required (as on the set
    form). Cardio Duration is optional on a logged set (an old set may have none) and required to un-skip a skipped
    one.
