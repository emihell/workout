# req-110 — Today: a multi-routine day reads as one day

## Technical

- `src/views/Today.jsx`: the per-slot `TodayWorkout` (date + name + Start each) is now
  `TodayWorkouts` (the one `.ui-today-workout` block, date line **once**) + `TodayRoutine`
  (name — focus, then its own primary full-width Start or `Done …`). `Today()` renders one
  `<TodayWorkouts todays=…>` instead of `todays.map(TodayWorkout)`. One routine → the exact
  pre-req-110 markup (date, name, Start; no wrapper). Two+ → each routine wrapped in
  `.ui-today-workout__routine`, schedule order (the `slotsOn` order, unchanged).
  `TodayHero` (DEC-038) still replaces the whole block — untouched.
- `src/ui/ui.css`: `.ui-today-workout__routine + .ui-today-workout__routine { margin-top: var(--ui-s4) }`
  so each Start groups with the name above it.
- `src/views/today.test.js` (new, static-source, 5 tests): date printed once and outside the map;
  `Today()` renders one grouped block; each routine's Start threads its own `slot` (→
  `scheduleSlotId`) and Done uses `coveringWorkout(…, slot.id)`; single-routine branch has no
  wrapper; the spacing rule exists.
