# req-176 — Finish lists what's unfinished before you save

Branch `req-176` (off `669a9e5`). UI only; Save's output is unchanged. `src/workout-log.js` not edited.

## Technical

- **`src/finish-unfinished.js`** (new, pure). `finishSkippedByItem(workout)` runs `withSkippedUnloggedSets` on the
  workout with its first 1, 2, … n items. That function only appends, item by item in order, so the sets step i adds are
  exactly what the full Save call adds for item i. No second counting rule. `finishSkippedLine` turns one entry into
  a sentence, and `finishSkippedLines` returns the list in workout order. Items with nothing added get no line.
- **`views/workout/finish.jsx`** renders one `<p className="ui-sub">` per line, under the summary line and before the
  beat-last-time line. No pop-up, and Save/Abandon are unchanged.
- **Sentences:** `Leg curl: 1 of 3 sets. The other 2 will be saved as skipped.` / `Leg press: not started. 3 sets will be
  saved as skipped.` Singular forms: `The other set` and `1 set`. "Not started" means the item has no set logged at
  all. If only the warm-up is logged, the line reads `0 of N sets. N sets will be saved as skipped.`
- **An unlogged planned warm-up is named, not folded in** (my choice, as the spec allowed). The line appends `and the
  warm-up set`, or reads `The warm-up set will be saved as skipped.` when every work set was logged. Work counts stay
  the overview's work sets, and every set Save adds is accounted for on screen.
