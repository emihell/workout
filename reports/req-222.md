## Technical

**What changed**
- `src/workout-log.js`
  - `workoutPillState`: when `currentWorkoutItem` is null (nothing logged yet), the pill's item is the first not-done item in
    snapshot order (the overview's done test). All done or 0 items → still null. New field `countText` ("N/M"); `label` =
    `[lead, setText, countText]` joined by " · " → "GO · 1/9", "GO · set 2/4 · 3/7", "1:12 · set 2/4 · 3/7".
  - New `workoutPosition(workout)` → `{ current, total, done }` or null: M = snapshot items minus swapped-away originals; N =
    done items among those + 1, capped at M.
  - `itemSwappedAway` moved here from `views/workout/row-label.js` (which re-exports it, so `doneRowSuffix` and req-189's test
    are unchanged). It is the existing derived test: some snapshot item has `replacesItemId` = this item's key. **No new stored
    field** — the stop condition did not fire: `replacementItem` (`workout-log.js:272`) already writes `replacesItemId` on a Swap
    item only, and a plain Skip exercise has no such item.
- `src/ui/index.jsx` `WorkoutPill`: new `countText` prop, shown after the set count; in the aria-label as ", exercise 3/7".
  Skip mode (resting on its own log screen) unchanged: tail is "skip".
- `src/views/workout/rest.jsx`: passes `countText`. `src/ui/Showcase.jsx`: sample pill gets `countText="3/7"`.
- `currentWorkoutItem` is **unchanged** (its req-186/188 tests untouched); the fallback lives in `workoutPillState`, its only
  source caller (`grep -rn currentWorkoutItem src` → workout-log.js + tests).
