## Technical

- `src/route.js`: new pure `screenChanged(prevHash, nextHash)` compares the two hashes' paths with the `?query`
  stripped. `useHashRoute` keeps the last shown hash in a ref, and a `useLayoutEffect` on `hash` calls
  `window.scrollTo(0, 0)` when `screenChanged` is true. It runs before paint, so the old offset never shows on the new
  screen. That is one place, the only one that scrolls. Same-path re-renders don't change `hash`, so they never scroll.
