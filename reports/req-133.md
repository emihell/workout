# req-133 — library tagging pass (report)

Branch `req-133` off `main` @ 76fe623. Data only: no reader change (`git diff main -- src/exerciseCatalog.js` is empty), no stored-data change.

## Technical

**What changed**
- `src/library/common.js` (new): 162 common entries as one row each (id, pattern, equipmentList, primary, secondary, logAs, family, aliases, unilateral), plus the two consistency allow-lists, each with a reason. `commonExercises()` is a function, not a module-level map, so the app bundle drops the file.
- `src/library/own-exercises.js` (new): `OWN_EXERCISES` moved here from `exerciseLibrary.js` (re-exported from there), plus 6 new `own-*` entries carrying the legacy free-db-shaped fields (`equipment`, `category`, `instructions`, and muscles from the req-130 19-string table).
- `src/exerciseLibrary.js`: the DEC-062 structure as constants (`MUSCLE_TREE`, `FREE_DB_MUSCLE_TO_TREE`, `PATTERNS`, `EQUIPMENT`, `LOAD_EQUIPMENT`, `LOG_AS`, `PATTERN_PRIMARY`, `FREE_DB_EQUIPMENT_TO_LIST`); `muscleTreeProblems()` and `libraryProblems()` (one line per problem); `OWN_FIELDS` now also lists `muscles pattern equipmentList logAs unilateral common family`. `SEED_ALIASES` is gone: all aliases now live on the common rows. `deriveLibrary` merges the tags, derives `muscleGroups` for tagged entries from their primary tree tags (same labels and order), and **throws on any problem**, so `build-library.mjs` refuses bad data.
- `src/library/exercises.json`: regenerated, 885 entries (876 + 2 extras + 7 own). Rebuilding from the pinned source gives the same bytes (`cmp` → identical).
- `src/library/PROVENANCE.md`: "What is ours" lists the new fields and files.
- Tests: `src/req-133.test.js` (new, 56 tests), plus the sanctioned edits to `src/exerciseLibrary.test.js`.

**Choices the spec left open** (candidates for DEC-/planning review)
1. **Family of one:** the spec says it "equals `fam-` + the entry's own id", but free-db ids aren't kebab case, so it is `fam-` + the id kebab-cased (`Face_Pull` → `fam-face-pull`, `Hyperextensions_Back_Extensions` → `fam-hyperextensions-back-extensions`). Enforced by `ownFamilyId()`. 72 families in all.
2. **Pattern calls:** reverse fly, rear-delt raise, band pull-apart → `fly` (horizontal ab/adduction in either direction); dips (bars, bench, machine, assisted) → `vertical-push`; back extension and pull-through → `hinge`; leg press and hack squat → `squat`; step-up and Bulgarian split squat → `lunge`; GHR and Nordic → `leg-curl`; Turkish get-up → `core-stability`; mountain climbers → `core-stability` + `time`; bicycle crunch (free-db "Air Bike") → `core-rotation`; **sled push → `carry` + `weight-time`** (nothing better fits; distance isn't in the list); battle ropes and jump rope → `cardio`/`cardio`.
3. **Tag level:** overhead presses → `deltoids` (the spec's example); bench → `pecs`, incline → `upper-chest`, decline/dips/high-to-low cable → `mid-lower-chest`; rows → `lats rhomboids` primary.
4. **logAs:** band-assisted pull-up and band pull-apart → `bodyweight-reps` (a band's load can't be logged); machine-assisted pull-up/dip → `weight-reps` (per spec); back extension → `bodyweight-reps` (no plate); Russian twist → bodyweight only.
5. **Equipment:** `machine` accepts `machine`, `smith-machine` or `cardio-machine`; `other`/blank/null make no claim. Inverted row is `bodyweight` only, since the list has no "rack" and a barbell would count as load. Farmer's walk is `dumbbell kettlebell trap-bar`.
6. **`unilateral`:** true only where each side is its own set (14: one-arm row, cable lateral raise, Bulgarian split squat, standing leg curl, single-leg bridge, both kickbacks, concentration curl, side plank, wood chop, Pallof, side bend, one-arm KB swing, TGU). Lunges, step-ups and alternating raises are false.
7. **Free-db map = exactly the 19 strings.** The extras' *secondary* strings `rotator cuff` and `erector spinae` are not mapped. They are outside the req-130 table and nothing reads them.
8. **Near-duplicates skipped:** one entry per variant. So Jogging (Running kept), Barbell Full Squat, Machine Bench Press, Seated Barbell Military Press / Barbell Shoulder Press, Reverse Flyes (Seated Bent-Over Rear Delt Raise kept), the V-bar pushdown, Rope Straight-Arm Pulldown, Machine Preacher Curls (Machine Bicep Curl kept), Step Mill and Squat-style TGU are not common. "DB RDL" is an alias on Stiff-Legged Dumbbell Deadlift, not a new own entry.

**Spec receipts answered:** lateral raise → **Side Lateral Raise** (free-db has a standing dumbbell one, so no own-* entry); leg curl → **Seated Leg Curl**; dips → **Dips - Triceps Version** (the upright bar dip; "Chest Dips" is on the chest version). All 25 top-1s match the spec; none needed a reason.
