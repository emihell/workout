# req-244 — the workout pill, two lines (DEC-139, look A)

## Technical

**What changed**
- `src/ui/workout-pill.js` (new): `workoutPillLines({ clock, set, exercise, go, skip })` → `{ top, bottom, label }`.
  `top` is the clock or "GO". `bottom` is "Set 2 of 4 · Ex 3 of 7", built from the parts that exist and joined
  with " · ", so with no set count it is "Ex 1 of 7" and has no separator. With `skip` it is "Tap to skip rest".
  It is a separate `.js` because oxlint's `only-export-components` rejects a non-component export from `index.jsx`.
- `src/ui/index.jsx` `WorkoutPill`: the props `setText`/`countText` became `set`/`exercise` (`{ current, total }` or null).
  It renders `.ui-restpill__time` (line 1) and `.ui-restpill__sub` (line 2). `.ui-restpill__sep` and `.ui-restpill__set` are gone.
- aria-label: "Rest 1:12, set 2 of 4, exercise 3 of 7 — open the exercise" / "Go, …". With skip: "Rest 1:12 — tap to skip the rest".
- `src/views/workout/rest.jsx`: `set` = `{ pill.current, pill.total }` only when `pill.setText` is non-empty, which keeps req-203 §7's
  "no set count before a set". `exercise` comes from `workoutPosition(active)`, the same call that `workoutPillState` makes for `countText`.
  **`workoutPillState` is unchanged.** I chose to format words from numbers and not to parse "3/7".
- `src/ui/ui.css`: `.ui-restpill` is now `flex-direction: column; align-items: center`, and `white-space: nowrap` stays on each line.
  New token `--ui-restpill-line2: 1.2` (line-height of line 2).
  `--ui-restpill-h` = `emphasis(28) + body(17) × 1.2 + 2·s2 + 2px` ≈ 66.4px (was 46px). `.ui-screen--rest` still reserves it through the
  same formula. Showcase-only rule `.ui-showcase__pill .ui-restpill { position: static; transform: none }`.
- `src/ui/Showcase.jsx`: four pills show at once (rest, GO, GO with no set count, skip), each with a caption.

## Workflow
- Choice the spec left open: the view formats the words from `{ current, total }` (no parsing), and `exercise` comes from
  `workoutPosition` in `rest.jsx`. This means `workoutPillState.countText`/`label` no longer feed what the user sees. They are now used
  only by tests (req-203, req-222). They could be removed in a later req.
- Choice: the skip aria-label is "Rest 1:12 — tap to skip the rest" (it was "… — skip the rest"). The new label still matches req-192's `/skip the rest/`.
- "Ex" (not "Exercise") as the req specifies, marked `(unconfirmed)` there.
- A possible L-: a pure helper exported from `ui/index.jsx` fails `./check` lint (`react(only-export-components)`). Put it in a sibling `.js` file.
- No scope added or dropped. No stored-data change.
