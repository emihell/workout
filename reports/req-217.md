**Choices the spec left open**

- Reps label wording: **"Reps each side"** (log form and edit sheet); the empty-field error reads "Enter reps each side".
- Warm-up rows of a unilateral exercise also read "each side" (same exercise, same rule).
- Timed / cardio amounts get no "each side" (spec says reps); e.g. a unilateral timed hold still reads "30s".
- "This exercise's rest" = rest running **and** the latest set record is this item's. A routine item with no rest (`restSec` 0)
  never shows its note on the log screen any more (it still shows on the review).
- Until the library chunk resolves (first open, a beat) the screen shows plain reps / note-only, then updates; a failed load stays
  that way silently.
- Block heading: none visible; `aria-label="While you rest"` on the section.
