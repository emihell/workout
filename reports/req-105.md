# req-105 — Finish becomes a bottom button, primary once everything's done

## Technical

- `src/workout-log.js`: new pure `allItemsDone(workout)`. It returns true when every `snapshot.items` entry is
  `itemIsMarkedDone || itemLoggingState(...).plannedDone`, and false for an empty or missing workout.
- `src/views/workout/overview.jsx`: the inline `items.every(...)` is replaced by `allItemsDone(active)`,
  and that one `allDone` both gates the req-84 summary and styles Finish. The Finish `<List><Row>` is
  replaced by a `NavLink` with `ui-btn ui-btn--{primary|secondary} ui-btn--block` (DEC-040: it only
  navigates, so no `go()`). It is stacked above Abandon in a new `.ui-workout-end` wrapper. The
  empty-workout branch is unchanged.
- `src/ui/ui.css`: `.ui-workout-end` is a column flex with `gap: s2` and `margin-top: s4`, which sets it
  apart from the list. `.ui-btn--block` gains `box-sizing: border-box`. Without it, the first screenshot
  showed the block anchor overflowing the right edge by its padding and border, because only `<button>`
  is border-box by browser default. Domino check: `ui-btn--block` is otherwise applied only by
  `<Button block>` (`src/ui/index.jsx:23`), which is already border-box, so those buttons are unchanged.
- Tests: `allItemsDone` gets 6 unit cases in `src/workout-log.test.js`. The new
  `src/views/workout/overview.test.js` checks the overview source as text (no Finish Row; Finish is a
  NavLink above Abandon with the primary/secondary switch; the box-sizing rule; one `allDone` drives both
  uses). No existing test was edited.

Receipts:
- `./check` → `check: green — lint, 23 test file(s), and the build all passed.`
- `node --test src/views/workout/overview.test.js src/workout-log.test.js` → `# pass 62 # fail 0`. This
  includes "is false with the last item done and the first open" and "is true when every item is
  planned-done".
- Browser run: a scratch puppeteer driver booted `dist/` with a seeded `activeWorkout` (sess-push-pull,
  8 items), scrolled to the bottom and probed the Finish element:
  - not done: `A` `ui-btn ui-btn--secondary ui-btn--block`, rect [24,630,366,674] in a 390x844 viewport,
    and the topmost element at its center is Finish. Clicking it went to `#/workout/sess-push-pull/finish`
    (h1 "Finish").
  - all done: the summary rendered (controls `Edit | Cancel`). After clicking Cancel, Finish is
    `ui-btn--primary ui-btn--block` with the same rect, and the topmost element at its center is Finish.
- Screenshots (gitignored, taken after the fix): `screenshots/req-105-not-done.png` (via `npm run shot`),
  `screenshots/req-105-not-done-bottom.png` and `screenshots/req-105-all-done-cancelled.png` (scratch driver:
  `npm run shot` can't click Cancel, because the dismissed state lives only in React component state). No
  bottom dock shows on this screen at 390x844.

Choices the spec left open:
- Finish is **full-width in both states**, and only the variant changes (secondary to primary). It
  matches the full-width Abandon under it. I read the spec's "primary, full-width" as naming the
  all-done look, not as ruling out full width before that.
- No chevron on Finish. It wears the button look, per DEC-040.
