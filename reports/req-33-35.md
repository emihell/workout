### req-33 — `plan doctor`

Added `cmd_doctor` to `plan` (+ `usage()` entry + `doctor)` case). Read-only:
reads config + filesystem only, never mutates. Six checks, each printing `ok` or
`FIX: … <exact command to run>`; any FIX makes the command `exit 1`.

1. **Layout** — parses `git worktree list --porcelain` for a `planning` + a code
   worktree. Deliberately does **not** call `find_worktrees` (which `exit 1`s on
   the first miss): doctor must report *all* failures in one pass, and the
   missing-planning-worktree case is the specific one it exists to explain (the
   two-separate-clones trap), pointing at the README recovery block.
2. **hooks** — code worktree `core.hooksPath=.githooks`.
3. **deps** — `node_modules/` present in the code worktree.
4. **grants** — `<planning>/.claude/settings.local.json` exists.
5. **identity** — `user.name`/`user.email` both set, and email not host-local
   (`*.local` / `*.(none)`, the auto fallback git invents at commit time).
6. Ends by running `plan status` (layout + drift in one go).

**Choice left open by the spec — doctor's exit vs `plan status`'s exit.** `plan
status` can exit non-zero on *handoff drift*, which is not a setup problem. I run
it with `|| true` so doctor's exit reflects only the five setup invariants — so a
correctly-set-up-but-drifted machine still passes doctor. The status output is
still shown; drift is just not conflated with a broken setup. Flag if you'd rather
doctor also fail on drift.

README §Setup step 6 rewired from `plan status` to `plan doctor`.

### req-34 — close the gate holes

**CI now runs the real gate.** `deploy.yml` gets `- run: ./check` between `npm ci`
and the Pages build. `./check` is the single source of truth — CI can't drift from
what `plan publish` enforces. `./check` builds too (no `GITHUB_PAGES`), so the
existing `GITHUB_PAGES: 'true'` build below it stays as the only Pages-configured
build that ships. `paths:` filter untouched. (`check`/`plan` carry git mode
`100755`, so `./check` is executable after checkout.)

**Test glob fixed to recurse.** `check` previously globbed top-level
`src/*.test.js`. Replaced with `find src -type f -name '*.test.js' | sort` into
the `testfiles` array. **Not** bash globstar (`src/**/*.test.js`): globstar is
unavailable in the bash 3.2 macOS ships, and this must run on both macOS and the
Ubuntu CI runner — `find` recurses portably on both. The empty-match guard and its
message updated to `src/**/*.test.js`.
