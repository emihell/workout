## Workflow

- Nothing on disk is rewritten; no schema change. Untouched Save writes the stored string back verbatim for *every* value
  (so a stored `'2,5'` stays `'2,5'` until edited), which is stricter than the spec's "unparseable" case.
- Choices **(unconfirmed)**: a typed unreadable value blocks Save with the note; `4/5` is offered via note text pointing at
  the checkbox (no extra button); detail line omits `n/a` entirely (used to show "n/a"); unreadable stored value shows raw on
  the detail line; editor defaults empty; recommendations now move for `'2,5'`-style stored values.
- Add-exercise (`Exercises.jsx:160`) already saved `'n/a'`; unchanged.
- Lint: new `only-export-components` warning on `weight-step-field.jsx` (hook + component in one file, same as `Routine.jsx`).
